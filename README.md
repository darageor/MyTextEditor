# cs201_lab1_MyEditor

Μέρος πρώτο :

Η main του προγράμματος δέχεται το όνομα του αρχείου σαν argument και το προωθεί στην συνάρτηση
editor. Πριν την αρχή της συνάρτησης editor αρχικοποιεί σαν public final μεταβλητές τα maxlinelength (το
μέγιστο μέγεθος σε χαρακτήρες που μπορεί να έχει η κάθε γραμμή του αρχείου ), maxwordlength (το
μέγιστο μέγεθος σε χαρακτήρες που μπορεί να έχει η κάθε λέξη του αρχείου ), minwordlength (το ελάχιστο
μέγεθος σε χαρακτήρες που μπορεί να έχει η κάθε λέξη του αρχείου), buffersize (το μέγιστο μέγεθος σε
bytes που μπορεί να έχει ο buffer στο δεύτερο μέρος της άσκησης) και LineVisualizer (η μεταβλητή του που
υποδηλώνει εάν θα φαίνεται ο αριθμός της γραμμής ή όχι κατά την εκτύπωση ). Επιπλέον αρχικοποιεί μια
μεταβλητή bufferlength στην οποία θα κρατάμε το συνολικό μέγεθος του buffer που θα δημιουργήσουμε
στο δεύτερο μέρος της άσκησης.

Κατά την εκκίνηση της συνάρτησης editorαρχικοποιούμε τις μεταβλητές LineVisualizer και valueoflines (το
πλήθος των γραμμών που έχει το αρχείο) με μηδέν και την μεταβλητή currentline (κρατάει τον αριθμό της
γραμμής που βρισκόμαστε την κάθε στιγμη) με ένα , επειτα περνάμε την κάθε γραμμή του αρχείου σαν
ξεχωριστό node στην κλάση double linked list ( dll ) χρησιμοποιώντας την συνάρτηση append της dll η οποία
προσθέτει ένα node στο τέλος του της λίστας ( εάν δεν υπάρχει αρχείο με το συγκεκριμένο όνομα που μας
δίνεται τότε δημιουργούμε ένα ) και κρατάμε σε δύο μεταβλητές τύπου node την κεφαλή της λίστας ώστε
να μπορούμε μετά να χρησιμοποιήσουμε την μια για να μετακινιόμαστε κατευθείαν στην αρχή της λίστας
και την άλλη για να κρατάμε το node στο οποίο βρισκόμαστε την κάθε στιγμή. Τέλος παίρνουμε στην
μεταβλητή command την εντολή που θέλει να εκτελέσει ο χρήστης και σε ένα loop την εκτελούμε εάν
γίνεται .

Εάν ο χρήστης δώσει την εντολή ^ (go to the first line ) αντιστοιχούμε τις μεταβλητές currentline με ένα και
c_node (το node node στο οποίο βρισκόμαστε την κάθε στιγμή) με το node_head.

Εάν ο χρήστης δώσει την εντολή $ (go to the lust line ) αντιστοιχούμε τις μεταβλητές currentline με το
valueoflines και c_node με το τελευταίο node της dll όπως μας δίνεται από την συνάρτηση getlast της dll.

Εάν ο χρήστης δώσει την εντολή – (go up one line ) ελέγχει εάν βρίσκεται στην πρώτη γραμμή του αρχείου
κι εάν δεν βρίσκεται αφαιρεί ένα από την μεταβλητή currentline και αντιστοιχεί στην μεταβλητή c_node το
προηγούμενο node όπως αυτό της δίνεται από την συνάρτηση getprev της dll, αλλιώς ενημερώνει τον
χρήστη πως ήδη βρίσκεται στην πρώτη γραμμή του αρχείου.

Εάν ο χρήστης δώσει την εντολή + (go down one line ) ελέγχει εάν βρίσκεται στην τελευταία γραμμή του
αρχείου κι εάν δεν βρίσκεται προσθέτει ένα στην μεταβλητή currentline και αντιστοιχεί στην μεταβλητή
c_node το επόμενο node όπως αυτό της δίνεται από την συνάρτηση getnext της dll, αλλιώς ενημερώνει τον
χρήστη πως ήδη βρίσκεται στην τελευταία γραμμή του αρχείου.

Εάν ο χρήστης δώσει την εντολή a ( add one line after the current line) παίρνει από τον χρήστη το string της
γραμμής που θέλει να προσθέσει κι έπειτα ελέγχει εάν βρίσκεσαι στο τέλος του αρχείου ή εάν γράφει σε
άδειο αρχείο κι εάν όχι χρησιμοποιεί την συνάρτηση InsertAfter της dll (προσθέτει νέο node μετά το node
που βρίσκεται εκείνη την στιγμή αλλιώς χρησιμοποιεί την συνάρτηση append της dll και ενημερώνει το
c_node με το node που πρόσθεσε ο χρήστης και τέλος ενημερώνει τις μεταβλητές valueoflines και
currentline με τις σωστές τιμές.

Εάν ο χρήστης δώσει την εντολή t ( add one line before the current line) παίρνει από τον χρήστη το string
της γραμμής που θέλει να προσθέσει κι έπειτα ελέγχει εάν γράφει σε άδειο αρχείο και χρησιμοποιεί την
συνάρτηση appent αλλιώς ελέγχει εάν βρίσκεσαι στην αρχή του αρχείου κι εάν όχι χρησιμοποιεί την
συνάρτηση InsertBefore της dll (προσθέτει νέο node πριν το node που βρίσκεται εκείνη την στιγμή αλλιώς
χρησιμοποιεί την συνάρτηση push της dll (προσθέτει ένα node στην αρχή του αρχείου ) και ενημερώνει το
c_node με το node που πρόσθεσε ο χρήστης και τέλος ενημερώνει τις μεταβλητές valueoflines και
currentline με τις σωστές τιμές.

Εάν ο χρήστης δώσει την εντολή d (delete current line ) ελέγχει εάν υπάρχει η γραμμή που ο χρήστης θέλει
να διαγράψει κι εάν υπάρχει την διαγράφει με την εντολή delete της dll και ενημερώνει την μεταβλητή
c_node με τον επόμενο node από αυτόν που διαγράφηκε και τέλος ενημερώνει τις μεταβλητές node_head
και currentline εάν χρειάζεται καθώς επίσης αφαιρεί ένα από την μεταβλητή valueoflines . Εάν δεν υπάρχει
η γραμμή που θέλει ο χρήστης να διαγραφεί σημαίνει ότι το αρχείο είναι άδειο κι εκτυπώνει αντίστοιχο
μήνυμα.

Εάν ο χρήστης δώσει την εντολή l (print all lines) εκτυπώνει όλες τις γραμμές του αρχείου και το κάνει αυτό
εκτυπώνοντας επαναληπτικά την κάθε γραμμή με την χρήση της συνάρτησης ReadCurrLine της κλάσης
ReadFromAsciiFile (rfaf) . Τέλος εάν το αρχείο είναι άδειο εκτυπώνει κατάλληλο μήνυμα .

Εάν ο χρήστης δώσει την εντολή n (toggle whether line numbers are displayed when printing) ενεργοποιεί ή
απενεργοποιεί το toggle για την εκτύπωση του αριθμού της γραμμής κατά την εκτύπωση αλλάζοντας την
μεταβλητή σε μηδέν και ένα για απενεργοποίηση και ενεργοποίηση αντίστοιχα και εκτυπώνει κατάλληλο
μήνυμα.

Εάν ο χρήστης δώσει την εντολή p (print current line) εκτυπώνει την γραμμή του αρχείου στην οποία
βρίσκεται εκείνη την στιγμή ο χρήστης γραμμή με την χρήση της συνάρτησης ReadCurrLine της rfaf.

Εάν ο χρήστης δώσει την εντολή q ( end with no save) τερματίζει την λειτουργία του editor χωρίς να
ενημερώσει το αρχείο που εισήγαγε με τις αλλαγές που έχει κάνει .

Εάν ο χρήστης δώσει την εντολή w (write file to disk ) ενημερώνει το αρχείο που εισήγαγε ο χρήστης με τις
αλλαγές που έχουν γίνει μέχρι εκείνη την στιγμή με την χρήση της συνάρτησης save της κλάσης
WriteToAsciiFile(wtaf) .

Εάν ο χρήστης δώσει την εντολή x (save and exit) ενημερώνει το αρχείο που εισήγαγε ο χρήστης με τις
αλλαγές που έχουν με την χρήση της συνάρτησης save της wtaf και τερματίζει την λειτουργία του editor.
Εάν ο χρήστης δώσει την εντολή = (print current line number) εκτυπώνει τον αριθμό της γραμμής που
βρίσκεται εκείνη την στιγμή ο χρήστης.

Εάν ο χρήστης δώσει την εντολή # (print number of lines and characters) δημιουργεί μια μεταβλητή
sumofchar για να κρατάει το πλήθος των χαρακτήρων του κειμένου και καλώντας την συνάρτηση
ReadLinesAndChars της rfaf προσαυξάνει την μεταβλητή sumofchar με το πλήθος των χαρακτήρων της κάθε γραμμής.
Τέλος εκτυπώνει το πλήθος των χαρακτήρων και των γραμμών του αρχείου.


Κλάση file_dll :

Περιέχει την double linked list και όλες τις κλάσεις που χρειάζεται για εισαγωγή γραμμής , διαγραφή
γραμμής κτλ.
Όλες οι συναρτήσεις για την εισαγωγή γραμμής πριν προχωρήσουν στην εισαγωγή της κάθε γραμμής
καλούν την συνάρτηση checksize που ελέγχει το μέγεθος της γραμμής κι επιστρέφει ένα string ελέγχοντας
και διαγράφοντας εάν χρειάζεται τις τελευταίες λέξεις ώστε το τελικό string να μην υπερβαίνει το
maxlinelength χωρίς όμως να σπάει καμία λέξη ώστε να την “εξαναγκάσει” να χωρέσει στο μέγεθος που
έχει οριστεί.
Η συνάρτηση checksize κατά την εκτέλεσή της καλεί την συνάρτηση getfullstring η οποία επιστρέφει ένα
string μεγέθους όσο της έχει ορίσει η checksize χωρίς να απορρίπτει από αυτό τα σημεία στήξης.


Μέρος δεύτερο :

Εάν ο χρήστης δώσει την εντολή c (create the index file and print the number of pages that has ) τότε
καλείτε η συνάρτηση CreateIndexAndReturnPages της κλάσης index_file(index) η οποία καταχωρεί σε ένα
bite αρχείο τις λέξεις του κειμένου που έχουν ελάχιστο αριθμό χαρακτήρων minwordlength καθώς επίσης
όσες λέξεις έχουν μεγαλύτερο αριθμό χαρακτήρων από maxwordlength τις καταχωρεί στο αρχείο μέχρι το
σημείο που καλύπτουν το μέγιστο αριθμό χαρακτήρων που έχει δοθεί. Δίπλα σε κάθε λέξη καταχωρεί την
γραμμή του αρχείου στην οποία την εντόπισε. Η συνάρτηση αυτή επιστρέφει το μέγεθος του αρχείου που
δημιούργησε σε bytes το οποίο καταχωρείται στην μεταβλητή bufferlength και διαιρώντας το με την
μεταβλητή buffersize βρίσκει και εκτυπώνει το πλήθος των σελίδων του αρχείου αυτού.

Εάν ο χρήστης δώσει την εντολή v (print index) ελέγχει εάν το έχει δημιουργηθεί το index αρχείο κι εάν έχει
δημιουργηθεί τότε με την χρήση της συνάρτησης printall του index εκτυπώνει όλα τα δεδομένα από το
αρχείο index.

Εάν ο χρήστης δώσει την εντολή s (print lines of given word using serial search) τότε καλείται η συνάρτηση
ssearch του index η οποία κάνοντας σειριακή αναζήτηση στο index αρχείο ελέγχει εάν υπάρχει η λέξη που
αναζητάει ο χρήστης , μια ή περισσότερες φορές, και εκτυπώνει την γραμμή ή τις γραμμές στη οποία ή στις
οποίες υπάρχει αυτή στο αρχικό αρχείο. Εάν η λέξη δεν υπάρχει τότε εκτυπώνει κατάλληλο μήνυμα. Τέλος
η συνάρτηση επιστρέφει τον αριθμό προσβάσεων που έκανε στον δίσκο μέχρι τον τερματισμό της ο οποίος
αριθμός εκτυπώνεται και στον χρήστη.

Κλάση index_file:

Περιέχει όλες τις συναρτήσεις που χρειάζονται για την δημιουργία, εκτύπωση και αναζήτηση στο byte
αρχείο.
Όλες οι συναρτήσεις αναζήτησης χρησιμοποιούν την συνάρτηση stringCompare για τον έλεγχο ισότητας
μεταξύ της λέξης που εισήγαγε ο χρήστης για αναζήτηση και των λέξεων του index αρχείου. Η συνάρτηση
αυτή επιστρέφει μηδέν εάν οι δυο λέξεις είναι ίδιες , θετικό αριθμό εάν η λέξη που εισήγαγε ο χρήστης για
αναζήτηση είναι “μεγαλύτερη” ( πιο κάτω αλφαβητικά σύμφωνα με τον κώδικα Ascii ή μεγαλύτερου
μεγέθους σε χαρακτήρες ) ή αρνητικό αριθμό εάν η λέξη που εισήγαγε ο χρήστης για αναζήτηση είναι
“μικρότερη” ( πιο πάνω αλφαβητικά σύμφωνα με τον κώδικα Ascii ή μικρότερου μεγέθους σε χαρακτήρες).
Πριν από τον τερματισμό του editor καλείται η συνάρτηση deleteindex του index η οποία διαγραφεί το
αρχείο index εάν έχει δημιουργηθεί και εκτυπώνει κατάλληλο μήνυμα για την επιτυχή διαγραφή του
αρχείου ή μην .
